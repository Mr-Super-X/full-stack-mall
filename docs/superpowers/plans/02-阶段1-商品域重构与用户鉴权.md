# 阶段 1 后端实施计划：商品域重构 + 用户鉴权（2026-11-06）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
> **执行方式**：主会话逐文件实现（native），每个文件完成后自检并回看本计划。

**Goal**：商品域按转卖商城新模型重构（`Product` 身份字段 + 价格/库存/图片下沉 `ProductItem`/`ProductImage`），新增 `user/` 包实现 JWT 鉴权四接口（register/login/logout/me），`init.sql` 重写为全部 MVP 核心表 + 双货源种子；curl 可独立验收。

**Architecture**：沿用按业务分包与 Controller → Service → Mapper(MyBatis-Plus) 分层；鉴权采用**轻量自实现**（jjwt 签发/解析 + HandlerInterceptor + ThreadLocal 用户上下文），不引 Spring Security 全家桶；密码哈希用 `spring-security-crypto` 单模块的 BCryptPasswordEncoder；商品列表/首页聚合改为自定义 XML 聚合查询（`MIN(price)` 展示价），这是 MP 不覆盖 join 场景的既定出路。

**Tech Stack**：Java 17 · Spring Boot 3.5.9 · MyBatis-Plus 3.5.18.1（+jsqlparser）· MySQL 8.4（Docker 仅数据库）· jjwt 0.12.6（api/impl/jackson，已验证存在于 Maven Central）· spring-security-crypto（版本由 spring-boot-starter-parent BOM 管理，pom 不写版本号）· 本机 Maven 3.8.9 + JDK 17（不再用 Docker 构建）

**Spec**：[../specs/2026-11-06-resale-mall-design.md](../specs/2026-11-06-resale-mall-design.md)（§3 技术栈、§4 领域模型、§6 接口契约、§7 技术决策、§9 阶段 1 行、§10 slice1 重构表、§12 决策记录）

## Global Constraints

- 信封 `Result{code,message,data}`，code=200 成功；分页 `PageResult{list,total,page,pageSize}`；业务错误 HTTP 仍 200、code 见信封
- context-path=`/api`，Controller 映射以 `/mall` 开头；端口 18080
- 仅 `status=1` 商品对外可见；详情查不到/未上架 → code=404 "商品不存在"
- Entity 不出 Controller；出参一律 DTO；构造器注入（现有代码已是，保持）
- 单文件 ≤400 行；公共 API 附中文 Javadoc（用途/边界，不复述类型）
- 枚举存库用 name() 字符串（MP 默认 EnumTypeHandler），`owner_type`/`sale_mode`/`role` 均为 VARCHAR
- 金额一律 `DECIMAL(10,2)` / `BigDecimal`；时间表 `DATETIME` + `create_time/update_time` 默认 CURRENT_TIMESTAMP
- 无物理外键（逻辑外键，互联网项目惯例，沿用 slice1）
- commit message 中文约定式，禁止 AI 痕迹（frontend `check-commit-msg.sh` 同口径）
- MySQL：compose 13306:3306，库 `mall`，root `mall-root`（仅本地）；`init.sql` 幂等可重跑
- JWT 密钥走 `app.jwt.secret`（默认开发值 + 注释"生产必须环境变量覆盖"），过期 `app.jwt.expire-hours` 默认 24

## Review Focus（规格未明说但最易咬人的 6 处）

1. **用户名大小写**：MySQL `utf8mb4_unicode_ci` 不区分大小写，`Admin`/`admin` 视为同一——注册重名校验与登录查询都依赖 CI 行为，测试要断言（注册 `ADMIN` 后查 `admin` 命中）
2. **JWT 过期/篡改**：`ExpiredJwtException`/`JwtException` 必须捕获转 401，绝不允许漏成 500——AuthInterceptorTest 断言
3. **ThreadLocal 泄漏**：拦截器 `afterCompletion` 必须 `remove()`，否则 Tomcat 线程池串号——AuthInterceptorTest 断言清理后上下文为空
4. **`order` 是 MySQL 保留字**：订单表名用 `orders`，DDL 验证通过为准
5. **Cookie SameSite=Lax + 跨端口**：localhost 不同端口属同站（端口不计），Lax 放行 XHR，但前端必须 `withCredentials`——curl 验收用 `-c`/`-b` cookie jar 模拟
6. **GROUP BY 聚合排序**：`ORDER BY price`（MIN 聚合别名）+ 白名单 `<choose>`，非法 sort 静默回退 newest——e2e 断言 price_asc 首条为最低价商品
