## Global Constraints

- 信封 `{code,message,data}`，code=200 成功；分页 `{list,total,page,pageSize}`；业务错误 code 非 200
- axios baseURL 由 `VITE_API_BASE_URL` 注入；dev 环境值 `http://localhost:18080/api`（申请 1）
- 请求必须 `withCredentials: true`（shared http.ts 默认）；Cookie HttpOnly 前端不可读，登录标记仅 `Session.set('auth', true)`
- 异步 UI 必须显式三态：Loading（useRequest.loading）/ Error（useRequest.error + 重试按钮）/ Empty（useRequest.isEmpty）；禁止 return null 式留白
- 提交类按钮（登录/注册）请求进行中必须禁用或显示 loading，防重复提交
- 列表/详情字段平移：后端 `sellingPoint` → 前端 `minitag`；`price` 语义=最低规格价（"¥xx 起"）；寄卖商品 `conditionGrade` 非 NEW 时卡片显示成色角标
- 组件 ≤300 行；BEM 命名空间 kebab-case 与 sass 根选择器严格对齐；不新增 `console.log`（生产代码禁）
- 类型禁 `any`；外部输入用 zod schema（`requestValidated`）或 `unknown` + 窄化
- 单测：新增 composable/store/类型必须带 `.spec.ts`（AGENTS.md 项目约束 6）

## Review Focus（规格未明说但最易咬人的 6 处）

1. **CORS 跨域 Cookie**：dev 前端 5177 → 后端 18080 跨端口；后端 CorsConfig 已允许凭证，但前端 axios 必须 `withCredentials: true`（shared 默认）且后端 `Access-Control-Allow-Credentials: true`——e2e 登录后 Cookie 写入即验证
2. **401 登录态探测误跳**：`fetchProfile`（http.ts `/auth/profile`）与我们的 `/mall/auth/me` 是两个不同端点；阶段 1 只用 me，不碰 profile 守卫链——避免触发 http.ts 的 refresh/redirect 副作用
3. **分页适配器**：`usePageAdapter: true` 时 http.ts 自动抽 page/pageSize 注入后端查询参数；列表页必须传 `usePageAdapter: true` 才能正确分页（首页聚合接口非分页，不传）
4. **图片 URL 空值**：`imageUrl` 可能为 null（后端聚合子查询无结果时），卡片组件必须 `v-if` 兜底到 MallPh 占位块（原型已有此设计）
5. **登录按钮防重**：`useRequest` 的 `loading` 态必须绑定按钮 `disabled`，否则快速双击会发两次请求
6. **路由白名单**：登录/注册页必须 `requiresAuth: false` 且被 `whitelist.ts` 吸收，否则未登录用户被守卫拦截到登录页死循环

```ts
// apis/index.ts 导出类型与函数
export interface MallGoodsItem {           // 与 mall.ts 同名但字段映射到后端
  id: number; name: string; price: number; originPrice?: number | null
  imageUrl?: string | null; tag?: string | null; sellingPoint?: string | null
  garm?: string | null; sales?: number | null
  ownerType: 'PLATFORM' | 'CONSIGNMENT'; saleMode: 'NORMAL' | 'SECKILL' | 'CROWDFUND' | 'SUBSCRIPTION'
  conditionGrade: 'NEW' | 'LIKE_NEW' | 'GOOD' | 'FAIR'
}
export interface MallProductDetail extends MallGoodsItem {
  categoryId: number; sellerId?: number | null; detailHtml?: string | null; createTime: string
  items: MallProductItem[]; images: string[]
}
export interface MallProductItem { id: number; size?: string | null; color?: string | null; conditionGrade: string; price: number; originPrice?: number | null; stock: number }
export interface MallHomeContent { notice: string; banners: BannerItem[]; categories: CategoryItem[]; flash: FlashSection; news: MallGoodsItem[]; recommend: MallGoodsItem[] }
export const h5MallApi = {
  getHome: () => request<MallHomeContent>({ url: '/mall/home/content', method: 'get' }),
  getList: (params: { page: number; pageSize: number; keyword?: string; categoryId?: number; sort?: 'newest'|'price_asc'|'price_desc'|'sales_desc'; discountOnly?: boolean }) =>
    request<{ list: MallGoodsItem[]; total: number; page: number; pageSize: number }>({ url: '/mall/product/list', method: 'get', params, usePageAdapter: true }),
  getDetail: (id: number) => request<MallProductDetail>({ url: `/mall/product/${id}`, method: 'get' }),
  login: (data: { username: string; password: string }) => request<{ id: number; username: string; nickname?: string; role: string }>({ url: '/mall/auth/login', method: 'post', data }),
  register: (data: { username: string; password: string; nickname?: string }) => request<{ id: number; username: string; nickname?: string; role: string }>({ url: '/mall/auth/register', method: 'post', data }),
  me: () => request<{ id: number; username: string; nickname?: string; role: string }>({ url: '/mall/auth/me', method: 'get' }),
  logout: () => request<void>({ url: '/mall/auth/logout', method: 'post' }),
}
```
