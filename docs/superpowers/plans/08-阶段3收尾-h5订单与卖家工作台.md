# 阶段 3 收尾（h5 tabbar 常驻 + 订单页 + 卖家工作台）实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** h5 移动端收尾——tabbar 常驻（切页不消失）、买家订单页（列表 + 确认收货）、卖家工作台（我的寄卖 + 接受定价 + 售出订单 + 发货），让阶段 3 的「能运营的商城」在 h5 端可操作。

**Architecture:** tabbar 常驻靠**上移共享布局**：把 `MallTabbar` + `useMallTabNav` + activeTab 路由同步上移到 `layouts/h5/index.vue`（h5-mall 所有页共享），首页移除局部 tabbar。订单/卖家页是 tab 子页（挂 h5 layout，享常驻 tabbar）：买家订单（GET /mall/orders + 详情 + POST confirm）、卖家工作台（GET /mall/consignments/mine + accept + GET /mall/orders/sold + ship）。后端契约冻结（零后端改动）。

**Tech Stack:** Vue 3.6 + Vant 4 + Pinia + vitest（apps/h5 既有基建）；后端契约已钉死。

**Spec:** `docs/superpowers/specs/2026-11-06-resale-mall-design.md`（§6 订单/寄卖接口，plan-06 阶段 3 后端）

## Global Constraints

- 后端零改动（契约冻结）；不动 `packages/*`（方案已在阶段 3 落地，本计划纯 apps/h5 业务）
- 模块边界：h5-mall 模块自包含，路由/apis/composables/views 模块内强内聚（§1.2）
- BEM 强约束（§3）；AutoImport（vue/pinia/useAppRouter/createNamespace 不显式 import）；Vant 组件模板直接用
- 请求经 `request`（`@api/http`）；路由跳转 `useAppRouter`；提交防重
- 异步组件三态（Loading/Error/Empty，全局 AsyncState 组件）
- commit message 中文约定式，禁 AI 痕迹（约束 #11）
- 新增 composable / 类型必须带 `.spec.ts`（约束 #6）

## Review Focus

1. **卖家工作台身份**：seller 登录后工作台显示**我的寄卖 + 售出订单**；buyer 登录同 tab 显示**我的订单**（买家视角）。同一 tab 按登录用户角色/内容区分，不强制分 app（寄卖件 sellerId=当前用户即卖家）。
2. **确认收货/发货幂等**：confirm/ship 重复点击后端条件迁移返回 400（ORDER_STATE_ILLEGAL）——前端必须错误可见（toast）+ 刷新列表对齐真态，不留幻觉成功。
3. **tabbar activeTab 与路由同步**：切 tab 跳路由、浏览器前进/后退/activeTab 跟随路由（watch route.name），刷新页面 tab 选中正确。
4. **寄卖 accept 确认**：接受平台定价是铸造商品（不可撤）——useConfirm 二次确认 + 防重点击。
5. **未登录访问订单/工作台**：守卫跳登录（redirect 回跳），登录后回到目标 tab 页。
