# MISSION

## 技能

看懂 full-stack-mall 的 Spring Boot 后端（Java 17 + MyBatis-Plus + MySQL/Redis/RabbitMQ），从零开始、循序渐进，以本仓库真实代码为教材。

## 现实目标

**面试讲清这个项目**——能向面试官讲清楚架构决策与难点（统一信封、鉴权链路、事务与幂等、秒杀三策略对照、异步出单设计），从容应对「你项目里最难的技术点是什么」「为什么这么设计」类问题。
