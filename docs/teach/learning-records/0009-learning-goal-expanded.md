# 学习目标扩展为后端与部署掌控

2026-11-20，学习者披露自己具备前端开发经验、没有独立搭建后端项目的经验，并希望以当前项目为起点建立对后端和部署的掌控；随后明确要求用 `teach` 模式形成完整学习流程。这使原有“面试讲清项目”目标扩展为“能独立启动、读通、修改、验证、部署、排障和回滚”，面试表达保留为次级成果。

## 证据

- 学习者明确描述了前端背景与后端零基础，而不是由教师推测。
- 既有记录 `0006-course-completion.md`、`0008-backend-build-roadmap.md` 均指出测验答案未完整回收，因此不能把第 1～8 课的材料交付当成掌握证据。
- 学习者选择将上一轮报告转为正式文档，并建立完整学习流程，等于确认当前教学围绕新现实目标组织。

## 影响

- 保留第 1～8 课，不重复创建基础课；按新路线调整选读顺序，掌握状态统一保持“待验证”。
- 新增第 9 课“全栈运行与部署地图”，先建立运行地图和配置、卷、健康检查的基础，再进入部署实操。
- 后续每课必须回收测验、实验和教回证据；教师依据证据更新最近发展区，不再仅因学习者要求“继续”就默认前一课已掌握。
- `GLOSSARY.md` 暂不创建，等待学习者展示对术语的正确使用。
